# Decision Log — IT Application Knowledge Graph UX

*Canonical memory and audit trail.*

---

## 2026-06-12 — Initial Design Session

### D-UX-001: Primary brand color — #1D3269
KSquare Group primary navy. All sidebar, primary button, and brand elements derive from this.
Source: Uday Kumar, 2026-06-12.

### D-UX-002: Accent color — #00A8CC (Teal) — Variation 2 selected
User selected "Navy + Teal" from 5 color theme options. Teal signals modern health-tech platform intelligence. Used for active states, CTAs, badges, chart highlights, and interactive affordances.
Source: Uday Kumar, 2026-06-12.

### D-UX-003: Design direction — "Glass Platform" (Direction 2)
Airy, elevated. Frosted glass cards. Generous whitespace. Rounded corners (12-16px). Soft shadows. Teal active states. Pill-shaped badges. Feels like Linear or Vercel dashboard applied to enterprise data tooling.
Source: Uday Kumar, 2026-06-12.

### D-UX-004: Glassmorphism sidebar
Left navigation sidebar uses: background rgba(29,50,105,0.88), backdrop-filter blur(16px), border-right 1px solid rgba(255,255,255,0.12), box-shadow 4px 0 24px rgba(29,50,105,0.18). Width 240px expanded, 64px collapsed.
Source: User brief, 2026-06-12.

### D-UX-005: White main content background
Main content area is always #FFFFFF. No dark mode in MVP.
Source: User brief, 2026-06-12.

### D-UX-006: 5 navigation surfaces
Dashboard, Query, Analytics, Redundancy Explorer, Applications. Sidebar nav is the primary navigation pattern.

### D-UX-007: Form factor — responsive web (React JS)
Primary surface is desktop/laptop (1280px+). Responsive down to 768px. No mobile-first layout required for MVP demo.
Source: PRD, 2026-06-12.
